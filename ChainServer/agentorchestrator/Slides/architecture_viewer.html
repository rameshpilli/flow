📋 Decision Points Guide

  • Execution Model: Choose DAG for parallel execution or Sequential for simple workflows
  • 5 Summarization Strategies: Map-Reduce (best for large docs), Refine (iterative), Stuff (simple), LangChain (integration), Custom (your logic)
  • 4 Agent Classifiers: LLM-based (most accurate), Embedding (fast), Keyword (simple), Custom (your rules)
  • 4 Vector Stores: Chroma (local), Pinecone (cloud), Qdrant (hybrid), Cohere Compass (enterprise)
  • 3 Isolation Levels: None (shared), Partial (recommended), Full (complete separation)

Development: Use In-Memory stores, skip observability, use env vars for secrets

Production: Use Redis, enable OpenTelemetry, use Vault/AWS for secrets, enable OAuth

All environments: Configuration via environment variables - no hardcoded credentials
